# Pong

A simple Pong game I made to practice in Rust

## Prerequisites

- [``cargo``](https://doc.rust-lang.org/cargo/getting-started/installation.html)
- Someone to play with

## How to run

```
$ cargo run
```

## Usage (AZERTY keyboard)

- Left player presses Q/S to move
- Right player presses L/M to move

## Libraries used

- minifb
- minifb_fonts
- rand
